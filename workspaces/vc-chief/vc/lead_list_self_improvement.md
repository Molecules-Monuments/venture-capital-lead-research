# Lead List Self Improvement

Policy version: `3.0`; baseline source-yield guidance is proposal-only and cannot modify lists or cadence without required approval.

## Purpose

Improve source lists while keeping humans in control.

## Weekly review questions

- Which sources produced high-quality candidates?
- Which sources produced noise?
- Which source classes are missing from the thesis?
- Which sources are stale or rate-limited?
- Which newly discovered sources should be proposed?

## Agent authority

The system may propose changes to source lists.

Human approval is required before:

- Adding a paid source.
- Adding a login-gated source.
- Increasing crawl cadence materially.
- Adding a source that processes personal data.
- Removing a source that previously produced high-quality leads.
